# SESSION_REENTRY.md

Use this for a quick return to the project after a restart or when context is thin.

## Fast Reentry Order

1. Read `AGENTS.md`
2. Read `SOUL.md`
3. Read `USER.md`
4. Read `MEMORY.md`
5. Read `RECOVERY.md`
6. Read `SESSION_RECOVERY_PLAN.md` if deeper recovery is needed

## What to restore first

- Project identity
- Human preferences
- Active workspace context
- Any durable project changes that matter for future sessions

## Working rule

Do not make Christopher repeat stable facts if they already exist in the workspace files.
