    Navigation Structure Summary¶

    Current Routes (Clean & Organized)¶

    Primary Navigation: - / - Chat (home screen) - /dashboard - Dashboard overview - /agents - Agent monitoring - /settings - Redirects to /settings/general

    Settings Routes (pure route-based): - /settings/general - Application preferences - /settings/appearance - Theme and visuals - /settings/connection - Network hub - /settings/avatar - Avatar hub - /settings/desktop - Desktop hub - /settings/about - About page

    Detail/Sub-Pages: - /settings/tunnel - Tunnel configuration - /settings/daemon - Daemon settings - /settings/connection-status - Connection status - /settings/avatar/customization - Avatar customization - /settings/desktop/files - File operations - /upgrade - Subscription/upgrade

    Other Routes: - /setup - Setup wizard - /login - Login (web) - /callback - OAuth callback (web) - /gui-automation - GUI automation - /admin-center - Admin dashboard - /agent-status - Agent status - /brain-insights - Brain analytics
